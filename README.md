# Perfect Day in Your Dream City — Food Edition 🍴🌎

## About

**Perfect Day in Your Dream City — Food Edition** is an interactive food quiz that matches users with a dream city based on their food preferences. After completing the quiz, users can explore food recommendations and locations in their assigned city.

## How to Run

### Option 1: Clone the Repository

1. Clone or download this repository from GitHub.
2. Open the downloaded project folder.
3. Find the main **HTML file**.
4. Open the HTML file in a web browser.
5. Complete the quiz to find your dream city!

### Option 2: Download the Repository

1. Click **Code → Download ZIP** on GitHub.
2. Extract the ZIP file.
3. Open the project folder.
4. Open the main HTML file in a browser.
